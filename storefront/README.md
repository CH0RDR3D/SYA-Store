## Overview

SYA Storefront is the customer-facing ecommerce application powering the SYA Online ecosystem. Built on modern web technologies, it delivers a fast, responsive, and user-friendly shopping experience while integrating with a Medusa backend for product management, orders, customers, inventory, and payments.

### Tech Stack

- Next.js 14
- React
- TypeScript
- Tailwind CSS
- Medusa Backend
- Stripe & PayPal Payments
- MeiliSearch / Algolia Search
- AWS S3 / Cloudflare R2 / MinIO Storage

### Key Features

#### Ecommerce

- Product Catalog
- Product Detail Pages
- Category & Collection Browsing
- Advanced Search
- Shopping Cart
- Secure Checkout
- Customer Accounts
- Order Tracking & History
- Wishlist Support
- Multi-Region Commerce

#### Performance

- Server Components
- App Router
- Streaming & Suspense
- Static Generation
- Optimized Image Loading
- SEO Optimization

#### Integrations

- Stripe Payments
- PayPal Payments
- MeiliSearch
- Algolia Search
- S3 Compatible Storage

## Prerequisites

Before running the storefront, ensure you have:

- Node.js 20+
- Medusa Backend running
- PostgreSQL configured
- Package manager (npm, yarn, or pnpm)
